# Datasets

Every clip becomes one NPZ of raw landmarks (`clipstore.py`) plus a `reference_clips` row with `source`, `signer_id`,
`split`, `license` and `attribution`. Splits are always made **by signer**.

## Sources

| Source id | What | License (verified 2026-10-27) | Status |
|---|---|---|---|
| `own` | Recorder page / `record_cli.py` | Own recordings, signer consent | ready (P1) |
| `user` | "Add a sign" custom signs | user-contributed, local | ready |
| `kaggle_asl_alphabet` | Kaggle `grassknoted/asl-alphabet` (≈87k 200×200 images, **1 signer**) | **Verify on the Kaggle page** (couldn't be confirmed from search) | ingest script ready; needs your Kaggle download (ASK-2) |
| `asl_citizen` | Microsoft ASL Citizen: 83,399 videos, 2,731 signs, 52 signers, 42.8 GB zip | Microsoft research license: **non-commercial, non-revenue research only** | P2; partial remote-zip ingest (ASK-3) |
| `wlasl` | WLASL (YouTube/ASL sites URLs; many dead) | **C-UDA 1.0**: computational/academic use only, attribution on redistribution | P2 |
| `how2sign` | How2Sign sentence clips | **CC BY-NC 4.0** | ingest script ported (phrases only) |
| `islr` | Kaggle "Google – Isolated Sign Language Recognition" (Holistic 543 landmarks) | **Verify on the Kaggle page** | P2 optional |
| ~~`PYTHON/Data`~~ | 26 folders, 10,676 cvzone crops with skeleton drawn on, 1 signer | n/a | **Rejected**: MediaPipe detects a hand in <1% (1/255 sampled); a baked-in overlay and near-duplicate frames made the old 99.9% meaningless |

## Vocabulary

- Tier 1: A–Z. 24 static letters go to the static model; **J and Z are dynamic** (word model, P3).
- Tier 2: 50 words proposed in [PLAN.md §4](PLAN.md#4-proposed-vocabulary-ask-1), awaiting confirmation (ASK-1).
